# SIMULA landing topology

1. Utility header: sticky visual anchor, compact navigation, primary workspace
   CTA.
2. Sunrise hero: editorial promise, dual CTA, explicit evidence boundary,
   product UI.
3. Trust strip: four receipt anchors.
4. Context graph: connected input, authority, audience, method, limits, receipt.
5. Interactive rehearsal story: click-driven Frame, Rehearse, Decide states.
6. Boundary features: four pastel product principles.
7. Method split: editorial explanation beside structured result preview.
8. Dark CTA and quiet footer.

## System topology

1. Utility bar: logo and session action.
2. Fixed desktop sidebar: navigation plus persistent experimental boundary.
3. Main canvas: breadcrumb, title, forms, resources, status, result, provenance.
4. Mobile: sidebar becomes a compact horizontal navigation row; content stacks.

The landing is mostly static with ambient CSS motion. Product controls retain
direct click/hover behavior. Application workflows and data behavior are
unchanged.
