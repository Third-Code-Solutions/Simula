## Responsive model

- Desktop, `>= 960px`: sticky statement sequences; pinned five-step product story; horizontal galleries.
- Tablet, `640px–959px`: reduced pin distances; two-column cards; product steps become an ordinary document stack.
- Mobile, `< 640px`: compact floating header; single-column UI previews; no pinned content; all meaning remains visible without motion.

## Accessibility contract

- Semantic sections and unique labeled headings.
- Motion is progressive enhancement. `prefers-reduced-motion` receives static states.
- Keyboard-visible links and buttons.
- Decorative media has empty alt text; product diagrams have text equivalents in adjacent copy.
- No population claims, customer claims, or implied participant evidence.
