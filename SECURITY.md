# Security Policy

## Reporting a vulnerability

Please do not open public issues for security problems. Report them privately through GitHub:

1. Open the **Security** tab of this repository and choose **Report a vulnerability**
   (GitHub Security Advisories). This opens a private advisory visible only to the
   maintainers.
2. Include reproduction steps, affected components, and any suggested remediation.
3. If GitHub advisories are unavailable to you, contact a maintainer directly through
   GitHub with a link to a draft advisory.

## What to expect

- Acknowledgement of the report within a few business days.
- An assessment and remediation plan for confirmed issues.
- Credit in the advisory once a fix is released, unless you prefer to stay anonymous.

## Supported versions

Security fixes land on the `main` branch and in the newest artifacts published by the
`Sigstore-signed release` workflow. Older experimental tags are not maintained.
