# SIMULA Project Charter

## Mission

Build an independent behavioral-intelligence and campaign-simulation platform, initially focused on Philippine teams, that helps users compare stimuli, explore modeled audience response, expose disagreement and risk, and learn from later real-world outcomes.

## Product promise

SIMULA will communicate uncertainty and provenance. It will not present predictions as guarantees, replace human research, invent population distributions, or disguise heuristic and LLM output as validated measurement.

## Current mandate

Complete Phase 1 product and architecture definition from the Phase 0 evidence base. Do not create the Phase 2 application scaffold until Phase 1 exit criteria pass.

## Boundaries

- Public, licensed, consented, user-provided, or clearly labeled synthetic data only.
- No private competitor information, access-control bypass, copied identity, or unsupported implementation claim.
- No billing module in current scope.
- No production deployment or external production changes without explicit authorization.

## Success

Phase 0 and [[../plans/completed/001-phase-1-product-and-architecture-definition#Phase 1 exit criteria|Phase 1]] passed.
